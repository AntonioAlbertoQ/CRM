# CRM

Interface estática de login e cadastro em HTML, CSS e JavaScript.

Abra index.html no navegador para visualizar. Os fluxos de login, cadastro e recuperação de senha são demonstrações no front-end; ainda não estão conectados a uma API nem autenticam ou armazenam contas.

Arquivos da interface:
- index.html
- assets/login/css/style.css
- assets/login/js/main.js
